# Introducción a MATLAB

## Ejemplos básicos

* [calculo_coseno.m](calculo_coseno.m) calcula el coseno de un ángulo con su expansión en serie hasta alcanzar una tolerancia.
* [fact.m](fact.m) calcula el factorial de n de forma recursiva o iterativa para comparar tiempos.
* [pot.m](pot.m) calcula la potencia x^n con multiplicaciones sucesivas.
