# Ecuaciones diferenciales ordinarias

## Métodos de un paso

* [euler.m](euler.m) resuelve una EDO con el método de Euler.
* [heun.m](heun.m) resuelve una EDO con el método de Heun.
* [runge_kutta.m](runge_kutta.m) función que implementa métodos explícitos de Runge-Kutta de varios órdenes.
* [runge_kutta_ejemplos.m](runge_kutta_ejemplos.m) ejemplos de solución de EDO con Runge-Kutta.

## Métodos multipaso

* [Adams_Bashforth_Moulton.m](Adams_Bashforth_Moulton.m) función que implementa métodos de Adams-Bashforth-Moulton de varios órdenes.
* [ABM_2do_orden.m](ABM_2do_orden.m) método de Adams-Bashforth-Moulton de segundo orden.

## Aplicaciones

* [Lotka_Volterra_RK4_ABM2.m](Lotka_Volterra_RK4_ABM2.m) resuelve el sistema presa-depredador de Lotka-Volterra con RK4 y ABM2.
* [double_pendulum_RK4_ABM2.m](double_pendulum_RK4_ABM2.m) resuelve el péndulo doble con RK4 y ABM2.
* [sdof_sismo_RK4.m](sdof_sismo_RK4.m) calcula con RK4 la respuesta de un oscilador de un grado de libertad ante un sismo.
